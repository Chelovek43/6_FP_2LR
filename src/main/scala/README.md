# Лабораторная работа №1: Монады

## Вариант 7: Банкомат (ATM)

### Описание

Реализация симуляции работы банкомата с использованием функционального подхода и монад:

- **Reader** — для доступа к конфигурации (лимиты, комиссии, доступные купюры)
- **Writer** — для логирования операций и формирования чека
- **State** — для хранения и изменения состояния (балансы, касса, дневные лимиты)
- **IO** — для взаимодействия с пользователем через консоль


### Использование
После запуска программа предложит:

Выбрать пользователя — введите Alice или Bob

Выбрать операцию:

deposit — пополнить счет

withdraw — снять наличные

transfer — перевести деньги другому пользователю

nextDay — сбросить дневной лимит снятий

exit — выйти из программы

### Начальные данные
- Баланс Alice	5000 руб.
- Баланс Bob	3000 руб.
- Дневной лимит снятия	10000 руб.
- Комиссия за перевод	1.5% (списывается с отправителя сверх суммы)

Доступные купюры	5000, 2000, 1000, 500, 100

Наличие в банкомате	5000×2, 2000×5, 1000×10, 500×20, 100×50

### Возможные ошибки
- InsufficientBalance	Недостаточно средств на счете
- DayLimitExceeded	Превышен дневной лимит снятия (10000 руб.)
- NoCashForWithdraw	В банкомате нет нужных купюр для выдачи суммы
- InvalidAmount	Введена сумма ≤ 0
